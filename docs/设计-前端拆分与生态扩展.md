## 2. FR-5.1 前端拆分与构建（P0，其余项的前置）

- **拆分**：`frontend/index.html` 内联 JS/CSS → `frontend/src/css/*.css`（base/layout/components/pages/themes 五组）+ `frontend/src/js/*.js`（core/state/api/ui/recognize/generate/review/charts/history/pert/fast/gb/theme/i18n/audit 十五模块，按现有块边界切）。
- **构建**：`scripts/build_frontend.py`（零依赖）：按序拼接 css/js → 回写 `frontend/index.html` 单文件（保持 exe 自包含与现有加载方式）；**不引入框架/打包器**（PRD 明确"不引入框架"）。
- **守门**：构建前后 index.html 的 JS 语法 `node --check` 等价；`npm run build:frontend` 一键化；构建产物等价性由 M4 套件（S4/S5 全绿）保证——**AC：Playwright 等效冒烟全过（CDP 套件即等效实现）、构建一键化**。
- **收益**：为 UI03 组件化、ENG05 多语言、M5 主题维护提供文件级工作面。

## 3. FR-2.8 母版多选与列映射向导（P1）

- **母版目录**：`data/templates/`（xlsx + `<名>.meta.json`：名称/口径说明/列映射 {功能点,类型,重用,修改,US→目标列}）；默认母版 template.xlsx 映射内置。
- **列映射向导**（一次性接入新母版）：配置中心「母版」卡片 → 上传 xlsx → 选表头行 → 逐列下拉映射到母版字段 → 保存 meta（预览首行对位）。
- **生成时选择模板**：结果页导出区新增模板下拉（读取目录）；generate 按所选 meta 列映射写明细。
- **AC**：新母版映射后生成结果通过**列对位校验**（导出后 openpyxl 读回断言各字段落位）；旧默认母版行为不变（对拍）。

## 4. FR-3.3 复核表格组件化（P1）

- 抽取复核表格为 `frontend/src/js/component_table.js`：render(items, columns, rowRender, hooks) + 固定表头（sticky）+ 列宽拖拽 + 行展开 + **虚拟滚动**（仅渲染视口 ±20 行）。
- IFPUG 复核与 PERT 复用两处接入；**AC**：2000 行虚拟滚动流畅（滚动帧率断言 ≥60fps 近似：长列表渲染耗时 <16ms/帧抽测）、现有功能无回归（S5 全绿）。

## 5. FR-2.6 用户故事生成与工单推送（P2·轻量）

- 生成：按 INVEST 把确认的功能点转用户故事（标题/描述/验收标准/估算），**模板化生成**（非 LLM 依赖）；结果可编辑（textarea）后导出 Markdown/CSV。
- 推送：预留 `POST /api/story/push` 接口（provider/token 由用户配置；Jira/禅道/GitHub Issues 适配器接口占位），本期实现 GitHub Issues 一个适配器；推送失败返回明确错误 + 前端重试按钮。
- **AC**：生成可编辑后导出；推送失败有明确错误与重试。

## 6. FR-2.4 COCOMO II（P2·轻量）与 FR-1.9 互导（P2·轻量）

- **COCOMO II（Early Design）**：`gb_engine.py` 增 `cocomo_ii(kloc, scale Drivers...)`：PM = 2.94 × EAF × (KLOC)^E，E=0.91+0.01×ΣSF；结果与 IFPUG/NESMA 并排展示于快算页（KLOC 由功能点×语言换算系数推得，系数可配）；出处标注（COCOMO II 2000）。
- **互导**：IFPUG UFP → PERT：以 UFP×PDR 推乐观/最可能/悲观三点参考（±20% 带宽，系数可配）；PERT 页一键带入。
- **AC**（描述级）：结果并排展示、换算系数可配置并标注出处。

## 7. FR-2.10 命令行模式（P2·轻量）

- `scripts/server.py --cli --docx xx.docx --out out.xlsx [--method 估算功能点] [--fast pre|est]`：无 GUI 跑通识别→（全确认）→生成全链路；退出码 0 成功/2 输入非法/3 生成失败；**AC**：无 GUI 依赖可跑通全链路、退出码语义明确。

## 8. FR-5.5 多语言（P2·框架就绪）与 FR-3.6 响应式（P2·轻量）

- **i18n**：文案表 `frontend/src/i18n/zh-CN.json` + `en-US.json`（骨架），运行时 `t(key)` 查表；本期完成**抽取与 zh-CN 全量回填**（构建脚本校验 key 完整性），en-US 骨架后续补。
- **响应式**：PERT/复核/结果页在 1024~1280px 折行（cfg-grid/r-grid 单列化，已有基础断点扩展）；**AC（描述级）**：最低 1024px 可用。
