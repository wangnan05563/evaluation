## 1. 目标与范围

- **FR-2.1（FE01，P0）NESMA 预估/估算法**：「快速估算」入口——预估法 `UFP=35×ILF+15×EIF`、估算法 `UFP=7×ILF+5×EIF+4×EI+5×EO+4×EQ`，输入即算，与详细法并排展示，公式出处标注（GB/T 42588-2023 / NESMA 2.1）。
- **FR-2.2（FE02，P0）GB/T 36964 方程法造价**：结果页新增「国标造价」页签——`AE = PDR × S × SWF × RDF`、`费用 = AE/174 × 费率 + 直接非人力成本`、`S = UFP × GSC × CF`；因子全部下拉选择并显示取值与出处；支持自定义覆盖并标注"人工调整"；造价随明细/因子实时联动并纳入报告导出。
- **FR-2.3（FE03，P0）费率与基准数据可配置**：配置中心「费率与基准」卡片（人月费率/功能点单价/PDR 默认 6.96/174 折算），按年度版本多套保存（CSBMK-2023/2024），估算时选用并记录；数据与代码分离；非法数值拒绝。
- **FR-2.7（FE07，P1）估算阶段与需求变更因子**：造价按阶段选 CF（预算 1.70/立项 1.45/招标 1.25/需求 1.10/设计 1.00），报告注明"本测算基于 XX 阶段，CF=1.45"。
- **不在本期**：FR-2.8 母版模板多选（M6 后续卡/阶段三）、COCOMO II（FR-2.4，P2）。

## 2. 现状盘点

- 前端 `#methodSel` 已有「预估功能点/估算功能点」双法切换（母版管线内）。
- FE01 的「快速估算」入口（无需 docx 的独立快算工具）与 FE02 国标造价页签均未实现。
- 配置存储先例：recognition_rules.json（M3）——费率与基准沿用该模式。

## 4. 页面与数据流设计

1. **快速估算入口（FE01）**：侧栏新增「快速估算」页——ILF/EIF（预估法）或五类计数（估算法）数字输入、算法切换即算；结果卡显示 UFP/规模/费用区间；按钮「按此结果进国标造价」；页面标注公式与出处。
2. **国标造价页签（FE02/FE07）**：结果页新增页签（与现有并列）——因子下拉（阶段 CF/业务领域×应用类型 SWF/开发语言×团队 RDF/GSC）+ 取值与出处即时显示（CSBMK-2023/GB 36964）+ 每因子「自定义」勾选框（覆盖基准值后标注"人工调整"）；S/AE/费用 逐级展示；明细或因子变更即算；快算与详细法结果并排。
3. **费率与基准（FE03）**：配置中心卡片——`data/rates_versions.json`（`{"CSBMK-2023":{pdr:6.96,rate:28000,unit_price:...,dnhc:0,swf:{...},rdf:{...}},"CSBMK-2024":{...}}`，增删改查 + 版本选用）；`/api/rates` GET/POST（坏数据 400：负数/超界拒绝）；估算时选用版本并记录进结果（meta.rates_version）。
4. **报告联动**：MD 摘要追加「国标造价」段（因子表+出处+阶段注明）；打印样式覆盖造价页签；成品 xlsx 追加「国标造价」sheet（同 brand_color 表头联动）。
5. **数据分离**：全部基准存 JSON（不发版可更新）✓ FE03 AC2。
