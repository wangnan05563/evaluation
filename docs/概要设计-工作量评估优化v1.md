# 概要设计 · 工作量评估工具优化（v1.0）

> 上游：`PRD-工作量评估工具-v1.0.md`（FR 机读索引见其附录 B）。
> 本文档为 `prd_to_plan.py` 提供模块表与风险表；模块划分按"能力簇"组织，模块内 设计→实现→联调→验证 串行推进。

## 1. 架构约束（沿用现状）

- 本地 Python 标准库 HTTP 服务 + 单文件前端（frontend/index.html）+ Electron 壳 + PyInstaller sidecar；数据不出本机。
- 本期**不引入前端框架**（FR-5.1 仅拆分与构建）；所有新能力优先以"服务端引擎 + 现有页面扩展"实现。

### 2.1 依赖说明

- M5 依赖自身先行（令牌是暗色前提），与 M1/M2/M3 无耦合，可并行。
- M6 内部顺序：基准费率（FR-2.3）→ 方程法（FR-2.2）→ NESMA（FR-2.1）→ 阶段因子（FR-2.7）。
- M9 依赖 M1~M8 成果稳定后再动（拆分会触碰全部前端改动）。
