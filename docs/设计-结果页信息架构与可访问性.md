## 2. 现状盘点

- 结果页（v-result）现状：r-tabs 页签（评估汇总/国标造价，M6）→ .kpis（结论四值）→ #chartGrid（四图）→ .r-grid（明细表+分布）→ 导出区（dl-zone）。分区已天然存在但**无锚点导航、无折叠、无状态记忆**。
- 可访问性现状：M5 已实测对比度（light 13.57 / dark 11.87 / muted 5.71，均 ≥4.5:1）✓；键盘主链路（M3 快捷键）✓；缺口：图标按钮 aria-label、结果数值 aria-live、focus-visible 样式、折叠语义。

## 3. 信息架构设计（FR-3.2）

1. **分区锚点导航**：r-tabs 升级为「页签 + 锚点」双模式——顶部 sticky 导航条：`结论摘要 | 国标造价 | 明细 | 导出`。结论/明细/导出为汇总页内锚点（scrollIntoView + 高亮闪烁）；国标造价切换 gb 页签后锚定。当前区随滚动高亮（IntersectionObserver，节流 200ms）。
2. **分区折叠**：明细区与导出区加折叠按钮（`aria-expanded` + chevron 旋转）；默认「明细折叠」（首屏给结论）；折叠状态记忆（`localStorage('wl_fold')`，按分区键存储）。
3. **首屏给结论**：KPI 四值 + 四图保持首屏；明细默认折叠后首屏只剩结论与锚点条。
4. **与 M6 页签共存**：国标造价仍为页签（gbTab），锚点条中「国标造价」点击即切页签并定位。
5. **打印联动**：打印时全部展开（折叠状态不影响 PDF/打印完整性，TH04 复核）。

## 4. 可访问性设计（FR-3.5）

1. **iconbtn aria 补全**：全量盘点仅图标按钮（eye/showAllBasis/导出/折叠/删除等 ~15 处），补 `aria-label`；纯装饰 icon 加 `aria-hidden="true"`。
2. **结果数值 aria-live**：KPI 容器与国标造价输出区加 `aria-live="polite"`（明细变更/因子联动时播报）。
3. **焦点可见**：`:focus-visible{outline:2px solid var(--brand);outline-offset:2px}` 全局样式（令牌化，随主题）。
4. **折叠语义**：折叠按钮用 `aria-expanded` + `aria-controls`；锚点导航 `role="navigation"` + `aria-current`。
5. **审计方式**：axe 依赖不可用（离线），采用**手工审计清单 + CDP 脚本断言**（aria-label 覆盖率、aria-live 存在、focus-visible 样式、对比度复用 M5 实测、键盘链路复用 M3 用例）；审计结果留档 logs/。
