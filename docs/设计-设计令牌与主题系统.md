## 2. 现状盘点（设计依据）

- `:root` 已有 **11 个语义变量**（--bg/--card/--ink/--ink-2/--muted/--line/--line-2/--brand/--brand-ink/--brand-soft/--cyan），主体样式已走变量。
- 硬编码 `#hex` 共 **73 处**，主要残留：徽章/告警语义色（#D1FADF/#166534/#FFF7ED/#92400E/#D97706 等）、surface 微色（#FAFBFC×6）、M3 新增 errorBox #e05252。
- 无 data-theme；图表主题色已通过 `chartTheme()` 读 CSS 变量（M2 预留）✅。
- 无 `prefers-reduced-motion` 处理；打印样式已有（M2/TH04）。

## 3. 令牌体系设计（FR-3.1）

五组令牌，全部挂在 `:root`（亮色默认）与 `[data-theme="dark"]`、`[data-theme="contrast"]` 覆写组：

| 组 | 令牌 | 说明 |
|---|---|---|
| 色板 | 语义层：--c-primary/-success/-danger/-warning/-muted/-surface/-surface-2/-ink/-ink-2/-line + 既有 --brand 系列 | 现有 11 变量并入语义层命名（保留旧名作为别名一个版本期） |
| 字阶 | --fs-xs/sm/md/lg/xl + --lh-* | 现有 font-size 收敛为 5 档 |
| 间距 | --sp-1/2/3/4/6/8（4px 基） | 现有 margin/padding 收敛 |
| 圆角 | --r-sm/md/lg/pill | 卡片 16px、按钮 10px、pill 999px |
| 阴影 | --shadow-sm/md/lg | 玻璃卡片阴影收敛 |

**替换策略**：语义色映射表（#D1FADF→--c-success-soft、#166534→--c-success-ink、#FFF7ED→--c-warning-soft、#92400E→--c-warning-ink、#D97706→--c-warning、#e05252→--c-danger、#FAFBFC→--surface-2 …）逐条替换后以 `grep -E "#[0-9a-fA-F]{3,6}"` 校验归零（图标 SVG/位图白名单除外）。
**AC 复核**：改 `--brand` 一处全局生效（侧栏/按钮/图表/焦点环/选中态全部引用变量）。

## 4. 暗色主题（FR-4.1）

1. `[data-theme="dark"]` 变量组：bg #0F172A / card #1E293B / ink #E2E8F0 / line #334155 / brand 提亮 #60A5FA / surface 系列同步；徽章/告警语义色暗色版（降饱和、保对比度）。
2. **对比度**：正文 ≥4.5:1（dark: #E2E8F0 on #1E293B = 10.9:1 ✅），muted 文本 ≥4.5:1 用 #94A3B8。
3. **图表**：`chartTheme()` 已读 CSS 变量 ✅；补 dark 下网格线/tooltip 背景色令牌（--chart-grid/--chart-tip-bg）。
4. **三态开关**：配置中心新增「外观」卡片：亮色/暗色/跟随系统（segmented control）→ `localStorage('wl_theme_mode')`；应用逻辑：`applyTheme()` 设/移 `document.documentElement.dataset.theme`；「跟随系统」时监听 `matchMedia('(prefers-color-scheme: dark)')` change 实时响应（FR-4.3 同一实现）。
5. **切换即时生效**：纯变量切换无需刷新；ECharts 实例在主题切换时重新 `setOption` 换色。

## 5. 主题色定制（FR-4.2）

- 配置中心「外观」卡片：6 套预设（品牌蓝 #2563EB / 青碧 #0EA5E9 / 翠绿 #059669 / 琥珀 #D97706 / 玫红 #DB2777 / 石墨 #475569）+ 自定义 color input。
- 实现：写 `--brand`/`--brand-ink`/`--brand-soft`（自动由主色派生 ink/soft：HSL 降亮度/提亮 12%）；`localStorage('wl_brand')`；**导出表头联动**：`/api/generate` 请求携带 `brand_color` → generate_xlsx 母版表头填充色替换（保持母版样式完整性，仅替换表头 fill）。
- **非法色值拒绝**：`/^#[0-9a-fA-F]{6}$/` 校验 + 后端同校验，非法回退上次合法值并 toast。
- 实时预览：改色即时 `applyTheme()`。

## 6. 打印样式（FR-4.4）与高对比度（FR-4.5）

- 打印：M2 已实现；令牌化后复核——打印强制亮色令牌（`@media print { :root { ... } [data-theme] { ... } }` 覆写为亮色组），避免暗色打印费墨。
- 高对比度：`[data-theme="contrast"]` 纯黑白组（bg #000/ink #FFF/brand #FFFF00 focus），开关并入三态扩展为四态（亮/暗/高对比/跟随系统）。

## 7. 动效与插画（FR-3.4 / FR-3.7）

- 动效：上传区拖拽高亮（dragover 类）、识别中骨架屏（表格 skeleton 条）、步骤切换 150ms fade；全局 `@media (prefers-reduced-motion: reduce) { *{animation:none;transition:none} }`。
- 插画：emptyState/errorBox 的 icon 升级为内联 SVG 插画（文件夹/放大镜/警告三款，单色 currentColor 随主题）。
