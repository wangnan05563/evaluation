## 1. 目标与范围

- **FR-1.2 结果页图表摘要**：结果页首屏四图（类型分布/重用度分布/一级模块工作量占比/工作量三值区间），hover 数值提示、明细变更联动、图表可导出图片。
- **FR-1.3 多格式导出**：导出菜单提供 成品 xlsx（现有）/ 评估报告 PDF / 功能点 CSV / Markdown 摘要。
- **不在本期**：国标造价页签（FE-02，阶段二后续）、暗色图表配色（TH-01 接入令牌后适配，本期预留 CSS 变量接口）。

## 2. 图表技术选型

| 方案 | 评估 | 结论 |
|---|---|---|
| ECharts 5 UMD 本地化 | +~1MB exe 体积；hover/tooltip/图片导出（getDataURL/toolbox）开箱即用；单文件零 CDN | ✅ **采用** |
| 手写 SVG | 零依赖，但 hover 提示、图例、导出图片全要自研 | ❌ 成本高 |
| Chart.js | 体积略小但饼图/条形交互不如 ECharts 完整 | ❌ |

**落位与加载**：`frontend/echarts.min.js`（扁平目录，走既有 `/static/` 服务——注意该服务**不允许子目录**，见 server.py §do_GET 的 `/static/` 分支）；`index.html` 末尾 `<script src="/static/echarts.min.js"></script>`。**降级策略**：`typeof echarts==="undefined"` 时图表区渲染为数字表格（离线极端场景不阻塞），并 console.warn。

## 3. 图表规格（结果页首屏 2×2 网格，位于 KPI 卡与系统列表之间）

| 编号 | 图表 | 类型 | 数据源（全部前端聚合，无新接口） |
|---|---|---|---|
| C1 | 功能点类型分布 | 饼图（EI/EO/EQ/ILF/EIF 计数） | `items[].type` 分组计数 |
| C2 | 重用度分布 | 柱状（高/中/低） | `items[].reuse` 分组计数 |
| C3 | 一级模块工作量占比 | 横向条形（US 降序 Top15+其余合并） | 复用 `buildResult()` 已有的 `sys` 聚合（system→US） |
| C4 | 工作量三值区间 | 条形（低/中/高 人天） | `gSummary.work.{low,mid,high}` |

**通用要求**
1. hover 显示数值与占比（ECharts tooltip 默认）；
2. **联动**：`buildResult()` 末尾调用 `refreshCharts()`——重开修订/重新生成后再次进入结果页即重建（dispose 旧实例防内存泄漏）；
3. 导出图片：每图 `toolbox.saveAsImage`（png，命名 `图表名-<sid 基名>.png`）；
4. 主题：颜色从 CSS 变量 `getComputedStyle` 读取 brand/line/muted（TH-01 暗色时自动跟随）；
5. 容器高度 220px×2 行，窗口 resize 监听 `echarts.resize`。

## 4. 导出管线（结果页导出菜单）

入口：结果页 KPI 区右上角「导出 ▾」下拉（成品 xlsx = 现有 download() 行为保留为第一项）。

| 项 | 实现 | 验收要点 |
|---|---|---|
| 评估报告 PDF | **纯前端打印管线**：`@media print` 样式（隐藏侧导航/步骤条/按钮/下拉，KPI+四图在前、明细分页表头重复 `thead{display:table-header-group}`）+ `window.print()`，用户在系统对话框选"另存为 PDF"。**不引入 puppeteer**（保持零依赖）。PDF 图表需在打印前 `echarts.getDataURL` 替换为 `<img>`（打印时 canvas 可能空白） | 打印预览无导航/按钮元素；图表可见 |
| 功能点 CSV | 前端 Blob：`\uFEFF` BOM 头 + 全字段（seq/system/m1/desc/count_item/type/reuse/modify/cx），文件名 `<标题>-功能点明细.csv`，`URL.createObjectURL` 下载 | Excel 双击打开不乱码 |
| Markdown 摘要 | 模板：标题/生成时间/方法/KPI（UFP/US/调整后规模/工作量三值/费用三值）/四类分布表格/Top10 明细；先 `navigator.clipboard.writeText` 复制 + 下载 `<标题>-摘要.md` | 粘贴到邮件/文档格式完整 |

**不阻塞主线程**：全部同步小体积操作（明细 CSV 2000 行 ≈ 数百 KB），无大计算；图表序列化用 ECharts 自身 API。

## 5. 数据流与联动

```
render()/复核修改 → buildResult()（既有）→ refreshCharts()（新增：读 items 聚合 → setOption）
重开历史（FR-1.1）/重新生成 → goStep('result') → buildResult() → refreshCharts() —— 联动自动达成
echarts 缺失 → chartsFallback()：四图位置渲染 <table> 数字摘要
```
