## 1. 目标与范围

- **FR-5.3（ENG03，P1）接口入参校验**：统一校验层（dataclass），错误返回结构化 `{ok:false,msg,field}`。
- **FR-5.4（ENG04，P1）日志与诊断包**：结构化日志（级别/模块/耗时）；「一键导出诊断包」= 日志 + 脱敏配置 + 版本信息 zip。
- **FR-5.6（ENG06，P1）数据备份与迁移**：启动时自动备份 pert.db/config（保留 N 份）；数据结构版本号 + 迁移脚本；「导出/导入全部数据」。
- **不在本期**：FR-2.8 母版多选、FR-5.5 多语言、COCOMO II（P2）。

## 2. 现状盘点

- server.py 32 个 /api 路由：入参校验**零散**（recognize/generate/rules/rates 各自为政，错误形态不一，部分缺字段校验）。
- 日志：仅 print 散点（无级别/模块/耗时结构）。
- 数据文件（WE_DATA）：pert.db（估算历史）、estimation.db、recognition_rules.json、rates_versions.json、uploads/、generated/、template.xlsx。
- 无备份、无 schema 版本号、无导出/导入。

## 3. 接口入参统一校验（FR-5.3）

新增 `scripts/validators.py`（dataclass 校验器，零依赖）：

| 校验器 | 规则要点 |
|---|---|
| RecognizeIn | name 非空、b64 合法 base64 且 ≤50MB |
| GenerateIn | items 非空且每条 type∈枚举/reuse∈枚举/modify∈枚举、method∈{估算功能点,预估功能点}、brand_color 匹配 #RRGGBB（可选）、gb_state 数值域合法（可选） |
| RulesDoc | 每条规则 patterns 非空且可编译、priority 0~999、enabled 布尔 |
| RatesDoc | 复用 gb_engine.rates_ok（已有） |

**接入**：server 各 POST 入口 `V = check(payload, ValidatorX)`；失败统一 `400 {ok:false,msg,field}`（field 为出错字段路径，如 `items[3].type`）。校验失败写结构化日志（FR-5.4 联动）。**原则：只收紧明显非法输入，不改变任何现有合法行为**（回归由 M4 套件保证）。

## 4. 结构化日志与诊断包（FR-5.4）

新增 `scripts/slog.py`：
- `slog(level, module, event, **kv)` → JSON 行追加 `WE_DATA/logs/server.jsonl`（ts/level/module/event/duration_ms/自定义字段）；启动/识别/生成/规则保存/费率保存/备份/诊断包导出等关键事件埋点；print 保留（兼容既有日志 grep）。
- **诊断包**：`GET /api/diag` → 服务端打包 zip（`diag_YYYYMMDD-HHMMSS.zip`）：server.jsonl 近 7 天日志 + 脱敏配置（config 类 JSON 去除 api_key/token 字段后存档）+ version.json（app 版本/schema_ver/python 版本/路由清单）；**不含** uploads/generated（可能含用户业务数据，避免误传）。
- 前端配置中心「运维」卡片：一键导出诊断包（下载 zip）。

## 5. 备份与迁移（FR-5.6）

新增 `scripts/datakeeper.py`：
- **启动备份**：server 启动时把 pert.db、recognition_rules.json、rates_versions.json 复制到 `WE_DATA/backups/<ts>/`（保留最近 7 份，超出删最旧）。
- **schema 版本号 + 迁移**：`WE_DATA/schema_ver`（整数）；migrations 表 = `{1: fn, 2: fn...}`（每级一个幂等升级函数）；启动时逐级执行并写回。首版 schema_ver=1（迁移框架就绪、暂无迁移项，留扩展位）。
- **导出/导入全部数据**：`GET /api/data/export` → zip（pert.db + 三个 json + schema_ver）；`POST /api/data/import` → 校验 zip 内 schema_ver ≤ 当前 → 解包覆盖（导入前自动备份一份）→ 返回导入清单。前端配置中心「运维」卡片：导出/导入按钮。
